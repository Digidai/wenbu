# 问卜研究底稿：把传统符号做成可核对、可使用的工具

研究日期：2026-09-28。范围：公开产品页面、开源项目说明与授权、计算库与其测试、经典原文入口、论文公开摘要/书目、平台官方文档。本文是有范围的研究记录，不声称穷尽全部产品与流派，也不把公开阅读写成付费竞品实测。

## 结论与实现选择

**分析判断：**有机会的产品不是又一个要求输入姓名、生日后输出长篇命运断言的聊天框。可区分的体验是：立即可用的工具、能看清的命盘、明确的计算规则、用户主动选择的背景、可回看的手记，以及同一套工具被外部 Agent 调用。传统文化价值、计算正确性和预测有效性是三件不同的事。

首版选择八字、三钱易经、78 张塔罗、紫微斗数。前两者覆盖中文命理与问题式探索，塔罗覆盖不需生日的轻量入口，紫微提供具备结构的十二宫可视化。西方与吠陀星盘暂不直接提供：地理位置、恒星/回归黄道、岁差量、宫制和星历授权都需要独立实现与验证。奇门遁甲、大六壬、梅花易数、六爻纳甲、风水、姓名学、数字命理、灵摆与卢恩符文列入邻近领域地图，不能因掌握统一聊天提示词就宣称掌握其排盘。

## 计算与历法：可复核的工程部分

### 八字

采用 [lunar-typescript 1.8.6](https://github.com/6tail/lunar-typescript)（MIT）和 Temporal。主线：输入公历日期与当地时间/时区，计算绝对时刻；以 Asia/Shanghai 的绝对节气边界计算年、月柱；按用户选择的当地民用时或近似太阳时计算日、时柱。

具体约定：

- 年柱按立春、月柱按节气，不用春节或农历每月初一替代。
- 年/月柱的全球同一瞬间判断一致；日/时柱的当地钟表约定单列。
- 夏令时缺失或重复时间直接拒绝，要求明确 UTC 偏移，不默默选择早/晚一侧。
- 零点换日采用 setSect(2)，子初换日采用 setSect(1)。晚子时库的时干推算规则保留并展示。
- 未知时辰不生成时柱，年/月以中午暂定，交节日提醒不确定；不把中午显示为真实出生时间。
- 真太阳时采用经度与低阶均时差近似，标记误差边界，不自称高精度星历。
- 五行只统计明见天干地支各一个权重，不把“缺元素”直接解释成喜用神、身强身弱或健康问题。

上游回归样例：2005-12-23 08:37 为乙酉/戊子/辛巳/壬辰；1988-02-15 23:30 的两种换日差异分别验证。独立参照：[香港天文台 2024 年历](https://my.weather.gov.hk/en/gts/astron2024/files/HKO_almanac_2024.pdf)列立春为 2 月 4 日 16:27（香港时间）；测试取 16:26 与 16:28 两侧，避免分钟公布精度被误写成秒级证据。

### 紫微

采用 [iztro 2.6.1](https://iztro.com/quick-start)（MIT）。按当地公历日期、已知钟表时间、传统性别参数排盘；保留默认流派、fixLeap=true、晚子时索引12。展示十二宫、主星/辅星、四化信息与大限区间。测试对照官方 2000-08-16 寅时女性样例的木三局、命主破军、身主文昌。未实现太阳时校正、多个流派切换或未知时辰推断。

### 易经

三枚独立均匀二元随机值之和加6，得6/7/8/9，概率1/8、3/8、3/8、1/8。六爻按自下而上记录；6/9为动爻并翻转。64个比特模式到文王序一一映射，全部测试覆盖。使用 Web Crypto 拒绝采样避免取模偏差。此分布是三钱法，不冒称蓍草法。多动爻不假定一种全流派通用的裁决法。

### 塔罗

完整78张，22大阿卡那+56小阿卡那。部分 Fisher–Yates 抽样，无放回；逆位为独立50%抽取，可关闭。一张与三张“处境/张力/下一步”牌阵。所有现代提示文字与抽象卡面为原创，不抓取商业牌图、不复制现代译文；卡面视觉是统一原创纹样，不宣称是78幅 Rider–Waite–Smith 原画。

## 研究证据

[Shawn Carlson, Nature 318, 419–425 (1985)](https://www.nature.com/articles/318419a0) 是占星受控检验史中的一项双盲研究。这里只核实公开摘要与书目，未假装读过付费全文。它不能被扩写成对所有传统、全部流派和所有用途的一次终极检验。

[Forer (1949), DOI 10.1037/h0059240](https://pubmed.ncbi.nlm.nih.gov/18110193/) 是个人验证现象的原始研究书目入口。它提醒“主观觉得贴合”与“具备区别性和可检验预测”不同；本次确认书目，不宣称复现该课堂实验。产品因此避免空泛恭维、编造用户历史和用满意度代替准确率。

**可核实事实：**某个时间按约定计算得某个干支、卡牌抽样不重复、动爻按规则改变。
**传统解释：**某符号在一个传统中通常怎样被讨论。
**分析判断：**当前问题可能从哪些角度理解。
**待验证：**现实结局、心理收益、预测效果。生成的文字必须保持这些边界。

## 基础设施与模型

全部网站运行在 Cloudflare Workers、Static Assets、SQLite Durable Object 与原生 Rate Limit binding。模型只通过 [DeepSeek 官方 API](https://api-docs.deepseek.com/api/create-chat-completion/) 请求。指定 deepseek-v4-flash；[2026-09-10 官方变更](https://api-docs.deepseek.com/news/news260910/)说明该名字是过渡别名，需同时记录 requestedModel 与实际 servedModel。

MCP 遵循 [Streamable HTTP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)，无 isolate 内存会话、无自动导入私人上下文。八字等计算与 AI 解释拆开，即使上游故障也可使用免费工具。

## 接下来最值得做的验证

1. 找不同流派的实践者复核公开历法夹具，记录差异与明确选项，而不是先宣称“最专业”。
2. 经用户自愿测试，观察是否能在一分钟内完成一次计算、理解五行图的边界、找到保存与导出。
3. 用真实 Search Console 数据选择新增内容，不按虚构关键词量产门户页。
4. 获得合法授权及测试覆盖后，再考虑精确西方/吠陀星盘、奇门或六爻纳甲。
5. 针对非英语/中文用户、读屏用户、低端移动设备作后续实机测试。本轮浏览器测试范围见质量记录。

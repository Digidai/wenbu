# Agent 动效设计：纸墨成章

2026-09-28。延续纸张、墨绿与朱印的现有品牌，在独立 Agent 入口加入与真实执行状态相连的仪式感。[研究与取舍](../research/agent-motion-2026-09-28.md)。

## 构成

- `agent-activity.ts` 从已有消息及工具事件推导开场、查阅、计算、抽取、成文、继续、追问、结束与中断，不用时间伪造进度。
- `AgentRitual.tsx` 呈现装饰性 SVG、阶段文本、已读资料／已有结果的真实数量，以及可持久化的动效偏好。
- `agent-motion.css` 提供落印、纸页、细环、笔迹及结果结构轻微错峰。只在当前回合和实时到达的结果上使用；历史记录不重播。
- 工作台保留现有 SSE、模型、引用校验、结果与上下文流程。结果收到即渲染，动效结束不参与业务完成判断。

## 边界

首次渲染先静止，再读取页面偏好与系统减少动效设置。关闭动效不取消请求。停止、错误、限额、等待补充都收住循环，不显示成功状态。装饰性到达标记独立限时清理，导航与手动选版本立即清理；正文不使用透明或遮罩式延迟显示。

## 验收

使用明确标注的本地受控 SSE 逐段观察运动与状态，同时检查暂停、恢复、刷新、旧结果切换、四种图表、失败和追问。桌面 1280×800、手机 390×844，以及中文／英文分别检查。真实生产对话另行记录；本地回放不代表模型执行结果。Grok 审查与后续修复记录位于 reviews。

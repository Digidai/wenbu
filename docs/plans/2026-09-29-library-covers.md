# 知识手册：封面与文章列表

日期：2026-09-29。承接 [知识手册与新手路径](2026-09-29-library-content-design.md)。

## 问题与取舍

用户指出，扩充手册时改成纯文字目录，丢失了旧版封面的识别度。截图中的大字、纸色、双圆环是已有品牌资产。这次恢复这些元素，同时保留 21 篇指南、六个主题、新手路径、搜索与筛选。

默认使用带封面的文章网格，桌面三列、平板两列、手机一列。另一种“列表 / List”视图适合快速查找，但仍保留小封面。切换不会清空查询和主题，也不改变文章顺序。视图选择只作用于本页，刷新回到默认封面。

## 封面系统

- 21 篇手册与 2 篇札记拥有稳定的 slug → 封面映射；搜索、排序不会像原先的 nth-child 配色一样改变文章身份。
- 大字与细圆环延续旧版，加入四柱、五行、时间、六爻、八卦、十二宫、笔记与来源等线描主题；共 15 种图形类型，四种纸色。
- 塔罗三篇使用六张已生成的原创牌面缩略图，逆位文章把第二张牌翻转。复用 [原创牌组](../art/README.md)，无需重新下载大图或调用图像模型。
- 首页推荐、手册与札记共用 ArticleCover 组件。中文大字在英文版保留为品牌插画，标题、说明和操作完整翻译，不要求英语用户靠汉字理解文章。
- 图形用于识别主题，不是个人命盘，也不表达计算结论。六爻为六条线、八卦为八组不同三爻、十二宫为外围十二格，避免把装饰误画成错误数量。

## 可读性、交互与技术依据

整张文章卡片是一个链接，标题与摘要完整显示，不截断英文标题。元信息、标题、摘要与阅读入口有稳定顺序；同一行的阅读入口对齐。手机列表保留缩略图和全文，视图按钮最小高度 44px。

封面是紧邻文章标题的辅助插画，整体 aria-hidden；牌面空 alt，避免读屏器重复读标题或文件名。参考 [W3C 装饰性图片指引](https://www.w3.org/WAI/tutorials/images/decorative/)。

SVG 随 HTML 输出，不需要水合或图形脚本。封面预留 15:8 比例，牌图声明固有尺寸，使用原有 WebP 缩略图并延迟加载。参考 [浏览器图片延迟加载说明](https://web.dev/articles/browser-level-image-lazy-loading)。

仅在悬停或键盘聚焦时给出细微反馈。系统减少动效设置会关闭位移动画和过渡。没有自动播放的装饰动画。关闭 JavaScript 时，21 篇指南与全部封面可访问，搜索与切换控件隐藏。

## 审查与验收

Grok 首轮指出列表布局的 CSS 优先级会覆盖 hidden，已在真实浏览器复现并修复；同时把搜索读屏播报拆成独立延迟状态，输入停止 300ms 且数量改变后才播报，页面加载不主动播报。

发布证据见 [封面升级记录](../reviews/library-covers-release.md)。搜索词不写入统计；新增 library-view 仅记录 1（封面）或 0（列表），见 [统计口径](../analytics.md)。

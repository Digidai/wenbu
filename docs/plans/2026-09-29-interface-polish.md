# 中英文排版与交互收束

范围：现有全部中英文路由的响应式检查，重点验证 Agent 引导、资料、研究结果，以及四种独立工具的操作和结果。保留纸色、墨绿、朱砂和现有功能。

## 现场发现

- 1280 px 英文 Agent 侧栏把 I Ching、Zi Wei 拆成两行；短工具名称应作为完整单位。
- 320 px 英文资料弹窗中，长标签造成相邻输入框错位，部分选择值截断；页级无溢出不能代表表单可读。
- 320 px 中英文抽牌扇面超出表单容器，被外层裁切；铜钱和空态圆环也有小幅内部越界。
- 独立工具已有牌面揭示，但排盘/卦象结果、保存成功和 Agent 草稿插入缺少一致的动作反馈。部分可交互图表需要就近的简短提示。

## 取舍

1. 全局缩小英文：可减少换行，但牺牲可读性，且不能解决长标签与按钮布局。
2. 大面积装饰性动效：有视觉存在感，但分散阅读注意力。
3. **采用内容驱动排布和事件驱动反馈**：短名保持完整，长说明自然换行，窄表单降为单列；确认、保存、真实结果到达时使用一次短动效。

## 实现约束

- 输入框最小高度与标签布局独立；手机输入文字 16 px；重要文案不得省略截断。
- 选牌间距随容器缩放，保留每张牌的键盘操作。图表提示靠近图表，解读按钮的禁用原因就近说明。
- Agent 建议放入草稿后给出可编辑、尚未发送的回执；进度勾选、资料弹窗和通知使用 180–450 ms 的墨线/印记动效。
- 独立工具只在 API 真实返回后揭示结构，不新增等待时间、虚构步骤或百分比。旧结果互动不重复播放整份结果。
- 系统减少动效与 Agent 自带暂停选项均生效；状态消息可被辅助技术获知。

依据：[W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)、[Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)、[Status Messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)。这里作为设计与验收原则，不声称完成全面 WCAG 合规认证。

## 验收

全部生成路由在 320 / 390 / 768 / 1024 / 1280 px 检查页级与内部越界；人工检查中英文首屏、引导三步、资料表单、图表、报告与操作按钮。真实计算验证结果；受控 SSE 验证 Agent 等待/完成/失败，不将其当作模型质量证据。类型、现有回归、Lint、构建、站点审计、Grok、Cloudflare 和线上资源/浏览器验证分别记录。

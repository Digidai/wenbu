# 知识手册、双语表达与新手路径

用户希望知识手册更充实，首次使用更容易，并通过 Agent Team 全面审核文档和 GTM 表达。本次保留已有功能与文章链接，围绕实际使用问题扩充内容。

## 内容与阅读路径

原有 11 篇手册以概念介绍为主，缺少第一次操作、提问和看完结果之后的指引。新增 10 篇完整双语指南，形成 21 篇手册、2 篇札记，共 46 个语言版本。旧文补入具体练习，专业文分别核对十神、卦序、四化、历法和当前界面的显示范围。

目录按六个主题组织：第一次使用、八字、易经、塔罗、紫微、阅读与复盘。首屏先解决三个问题：选哪个工具、怎样提问、拿到结果后看什么。正文保留分节与来源，八篇关键指南增加三步图解或简短对照；手机提供可展开目录，文末连接相关指南及实际操作入口。

这轮扩充采用能读完、能练一次的短指南。篇数与字数不是质量指标；每篇需回答一个明确问题，提供例子、说明适用范围，并给出可以执行的下一步。

## 表达原则与 GTM

- 首页直接说明可以做什么、需要哪些资料，让新用户先选一个具体问题。
- 中文和英文分别编辑。保留专业术语并就地解释，避免抽象的“智慧、镜子、旅程”堆叠。
- 计算规则、传统解释、AI 推测和个人行动分开呈现；不把排盘精度写成预测准确率。
- 比较页以可核对的一手资料为依据，标明复核日期和来源，承认竞品已有的免费工具与规则说明。
- 免费页说明个人额度与共享预算；隐私页分清浏览器保存、发送至 DeepSeek 和两种导出内容。
- Agent、CLI、MCP 和 Skill 说明使用相同的能力边界。馆藏检索不宣传为全网搜索。

增长路径是“带着具体问题进入指南 → 看懂一个例子 → 打开相关工具或 Agent → 完成一次实际操作 → 自己决定保存与回看”。本次完成内容和入口，后续用真实访问与使用数据判断哪些主题帮助了用户，不以部署或新增页面推断流量、留存和排名。

## 实现与统计

全部指南、主题和跳转链接在服务端生成。搜索与筛选是渐进增强；关闭 JavaScript 后依然可以阅读完整目录。搜索支持中英标题、摘要、主题、工具和文章关键词；查询词留在浏览器，不写 URL、不发送统计。只统计搜索结果数量、分类选择和文章/工具入口点击，新增页面进入既有安全路径白名单。

保留 canonical、hreflang、站点地图及文章日期；知识手册使用 `CollectionPage` 与 21 项 `ItemList`，文章面包屑包含所属目录。新文章同时进入 Agent 的馆藏读取能力。这些是发现与引用条件，不等于已收录或获得流量。

结构依据：[W3C 页面结构教程](https://www.w3.org/WAI/tutorials/page-structure/)。语义标题、导航区域与有名称的搜索帮助不同阅读方式的用户定位内容；本轮不声称完成全面无障碍认证。

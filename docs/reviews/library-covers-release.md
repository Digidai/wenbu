# 封面与文章列表升级

日期：2026-09-29。基线：`8864549539866c6e2d31996a01deb10bd38a5909`。设计见 [封面系统](../plans/2026-09-29-library-covers.md)。

## 交付

恢复知识手册的大字、纸色和细圆环封面，并补充文章主题线描；三篇塔罗指南复用六张原创牌面缩略图。21 篇指南、2 篇札记采用稳定的封面映射，首页推荐、手册和札记使用相同组件。

手册默认封面网格，新增保留缩略图的列表视图。搜索、新手入口、六个主题、中英文内容和原有 URL 保留。所有标题和摘要完整显示，手机保留配图；悬停反馈支持减少动效设置，无持续播放动画。

## 审查与修复

真实 Grok CLI [首轮审查](library-covers-grok.md)指出两个问题：列表 display 规则覆盖 hidden，导致被过滤的文章重新出现；搜索结果的读屏播报过于频繁。

浏览器先复现列表显示三篇但状态为两篇的错误，然后修复 CSS 优先级。复验两个视图都只显示两篇匹配文章。视觉数量即时更新，独立读屏状态延迟 300ms、仅在数量改变后更新，初始不播报。[复核](library-covers-grok-final.md)返回无阻断问题。源代码审查与浏览器结果分别记录，不能互相替代。

Blocking defects:
1. **Reduced motion does not cover the new agent motion.** In `src/styles/agent-motion.css`, `.agent-draft-receipt`, `.agent-notice`, `.agent-context-dialog[open]`, `.agent-onboarding[data-ready='true'] .agent-guide-mark`, and the check-stroke rule animate transform or stroke. The change never adds a `prefers-reduced-motion: reduce` override, and `reading-motion.css` only disables its own selectors. Add the same explicit `animation: none` (and drop the stroke-dash animation) for those rules.
2. **Instrument labels can overflow, and the trailing icon is removed.** In `src/styles/agent.css`, `.agent-instruments a` is `white-space: nowrap` inside `repeat(2, minmax(0, 1fr))`, and `.agent-instruments a > svg:last-child { display: none }` drops the last icon. Long labels spill across the next cell instead of wrapping. Remove `nowrap` and the `display: none` rule; let the link wrap and keep `flex-shrink: 0` on the icon.
3. **Dismiss loses focus when a notice updates.** In `src/components/AgentWorkspace.tsx`, `key={notice}` is on the `role="status"` container that also holds the dismiss button, so a new notice remounts that button and drops focus. Put the key on the inner `<span>` only.
4. **The saved-state note is pulled over the action labels.** In `src/styles/reading-motion.css`, `.reading-saved-note:not(:empty)` sets `margin-top: -15px` against a base `margin: 10px 0 16px`, so the note overlaps the save/export row. Use a positive margin (about `8px`) and do not use a negative margin.

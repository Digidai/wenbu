## 实现依据与纠正的易误解点

- `package.json` 要求 Node `>=22.12.0`；独立 CLI 本身可用 Node 22。仓库运行与下载单个脚本的条件分别说明。
- `worker/mcp.ts` 公开四个计算工具和 `search_library`、`read_library`；不会调用 DeepSeek。`worker/agent.ts` 的内置 Agent 才有规划、外部读取、追问和报告工具。
- `worker/agent-library.ts` 的搜索结果包含外部来源元数据；`read_library` 只接受 guide/symbol。外部搜索结果的 `nextTool` 不能让 MCP 获得它没有公开的工具。文档要求宿主读取外链后再引用。
- MCP 默认 `locale=en`，`src/lib/schema.ts` 的 REST/CLI 路由默认 `zh`。接入示例显式指定语言；没有承诺所有传统名称均已翻译。
- `src/lib/journal.ts` 的导出资料包与 `worker/agent-schema.ts` 请求格式不同。特别是塔罗原牌只接受 `{id,reversed}`；出生输入在导出时可能被省略。文档给出选择与映射规则，不把导出 JSON 冒充即用请求。
- 应用不保存服务端会话正文，但 Cloudflare 会处理请求，使用 AI 时 DeepSeek 会接收消息及所选上下文。“浏览器保存”没有被扩写成“不出设备”“零保留”或“端到端加密”。
- `worker/agent.ts` 在流开始前预留第一次模型额度与一个网络回合，额外模型请求再原子预留。取消或失败仍可能占用第一次额度；没有承诺一定按完成次数收费或计数。
- 流式 `done.status=complete` 仅表示本回合执行完成；引用检查只证明来源已读取，均不等于每个模型结论经过独立事实核查。
- D1 daily SQL 按 UTC 日期分组，额度按上海午夜重置。`model_calls` 当前由 Agent 回合事件提供，不等于包括单次解读在内的完整账单。AI 引荐类别不证明模型引用或搜索排名。

## 生成文件核查

`scripts/generate-api.mjs` 只写 OpenAPI、Agent request schema 和 context schema。常规构建不执行该脚本；需在修改源头后单独生成。

`scripts/postbuild.mjs` 生成 `dist` 下 sitemap、robots、RSS、CSP headers 与 OG 图。`SKILL.md` 和 Agent 协议是手写文件。本轮未改共享脚本；两份协议保持字节一致。

# 中英文界面与仪式感优化

2026-09-29。范围：中英文页面布局、Agent 提问/资料/结果、四种独立工具的提示与反馈。设计与依据见 [方案](../plans/2026-09-29-interface-polish.md)。

## 修复与行为

- 英文侧栏短工具名保持一行，收起重复的装饰箭头，新建探索按钮保持完整；标题和选项按实际文字长度自然排布。
- 资料表单在窄屏改为单列，手机输入文字 16 px，输入框至少 44 px 高。桌面长标签不会挤压同一行的控件。保存后在原生对话框关闭完成后恢复输入焦点。
- 选牌扇面的展开距离跟随表单容器，320 px 不再裁切牌边；修正选中描边引用了不存在的颜色变量的问题。铜钱大小随可用宽度缩放。
- Agent 引导勾选、草稿回执、资料提示与弹窗使用一次短动效；插入草稿后明确说明可以修改再发送。通知换文案不会重建关闭按钮。
- 真实计算返回后，独立工具显示收束墨线；四柱依序展开、卦线自下而上展开，紫微选宫有轻反馈。保留原有牌面揭示，不增加人为等待时间。
- 图表补上点选五行、打开牌面看细节等提示；禁用解读按钮旁说明还缺问题还是分享确认；手记保存成功有明确回执。
- 修正塔罗结果页仍称牌面为“抽象图形”的旧说明，改为与当前资产一致的原创 AI 插画说明。

## 验证与审查

- 类型检查、139 项既有回归测试、ESLint、构建通过；69 个 HTML、64 个可索引页面、3193 个内部引用及 78 张牌面资产审计通过。
- [布局记录](polish-layout-local.json)：全部 69 路由在 320、390、768、1024、1280 px 扫描，并对修改后的牌面重新检查。页面无横向溢出。圆环/首页仪器的装饰变换允许越出自身盒子，实际仍在留白范围内；这类几何信号不计作内容裁切。
- [真实交互记录](polish-flow-local.json)：四种计算、键盘选牌、图表交互、保存与条件提示、资料保存焦点。保存提示距操作行 10 px；未保存时无额外空行；准备解读时未自动调用模型。
- [受控 Agent 回放](polish-motion-local.json)：英文报告在桌面和 320 px 可读，完成态 settled、等待补充 waiting、失败态 interrupted 各自正确；暂停动效期间回合继续运行。回放未调用真实模型。
- 系统减少动效时，四柱/墨线/引导/提示动画全部为 none；Agent 内暂停同样覆盖现有和新增动效。真实请求与结果不会被动画阻塞。
- [Grok 第一轮](interface-polish-review.md)：修复通知 key 引起的焦点风险，将保存回执改为清晰的正向间距。补充完整样式上下文后，[复审](interface-polish-final-review.md)确认减少动效和四个固定工具名的布局。
- Grok 随后误判 JSX 缩进会形成空白文本。实际构建 DOM 为 childNodes=0、:empty=true、display=none。向 Grok 提供该证据后，[最终复核](interface-polish-reconciliation-review.md)撤回该条并返回 **No blocking defects found**。不把工具退出码或未复现判断视作通过证据。

The agent completion KPI is wrong for capped explore turns. In `agentResponse`, entering the last model call does `limited = !reportCreated || toolCalls >= AGENT_TOOL_CALLS` before the model answers, and `done` then prefers `limited` over `complete`. Explore turns are not required to call `write_report`, and that last call cannot create one (`tool_choice: 'none'`). A normal explore answer that simply uses the last model slot is stored as `agent_finished` / `limited`. It drops out of `agent_complete` and out of `failures`, and the headline cards never show `agent_limited`.

Set `limited` only when required work was actually cut off: research still missing `write_report`, or the tool cap blocked a call the model still needed. If the final call returns text and no further tools, keep `complete`.

# Wenbu · 问卜

**先问清楚，再读结果。 · A clear question. A considered reading.**

[![Wenbu — old wisdom, a present perspective](https://wenbu.app/og.png)](https://wenbu.app/?utm_source=github&utm_medium=referral&utm_campaign=open-source-2026)

问卜是免费的双语命理与反思工具。可以从眼前的一件事开始抽牌、起卦，也可以核对出生资料对应的命盘，再查阅计算规则、图解案例与资料出处。

Wenbu brings BaZi, the I Ching, tarot and Zi Wei into a free bilingual workspace. Start with an everyday question, explore the actual chart or draw, then read the methods and sources behind it.

[Try Wenbu](https://wenbu.app/en/?utm_source=github&utm_medium=referral&utm_campaign=open-source-2026) · [中文网站](https://wenbu.app/?utm_source=github&utm_medium=referral&utm_campaign=open-source-2026) · [Handbook](https://wenbu.app/en/learn/) · [Connect an agent](https://wenbu.app/en/agents/?utm_source=github&utm_medium=referral&utm_campaign=open-source-2026)

- **For a question today:** tarot and the I Ching need no birth information. Keep one result and explore it through follow-up questions.
- **For a traditional chart:** BaZi and Zi Wei expose inputs, calculation conventions and uncertainty. Calculation accuracy does not establish predictive accuracy.
- **For learning:** 21 complete guides in Chinese and English, with diagrams, worked examples, sources and full Markdown/JSON editions.
- **For builders:** six remote MCP tools, a dependency-free CLI, an installable Agent Skill and REST schemas. No account or key is required for calculation and knowledge access.

问卜让传统符号、计算事实与自己的判断保持清晰。独立工具和手册免费；内置 DeepSeek Agent 可帮助查资料、整理札记与追问，受公开每日额度限制。
